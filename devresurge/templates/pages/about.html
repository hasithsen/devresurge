# DevResurge

DevResurge is a small, opinionated home for the IT crowd. Profiles read like a README — handle, headline, stack, projects, socials. Nothing more, nothing less.

## why?

Most “portfolio” sites either drown you in plugins or look like a CMS demo. We wanted something fast, accessible, and a little nostalgic — a terminal you can publish.

## stack

  • django + postgres on the back
  • hand-written CSS, no UI framework
  • django-allauth for auth + MFA
  • dark by default, light on demand
