# DevResurge

DevResurge is a small, opinionated home for the tech crowd. Profiles read like a README — handle, headline, stack, projects, socials. Nothing more, nothing less.

## why?

Most "portfolio" sites either drown you in plugins or look like a CMS demo. We wanted something fast, accessible, and a little nostalgic — a terminal you can publish.
